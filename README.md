# Hitesh Portfolio

My personal developer portfolio, built with React Native, Expo, and TypeScript.

## Features

- Responsive hero section
- About section
- Projects showcase
- Skills section
- Services section
- Contact section

## Run locally

Install dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```

## Build for the web

```bash
npx expo export --platform web
```

The exported website files are generated in the `dist` directory.
